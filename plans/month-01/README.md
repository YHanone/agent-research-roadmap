# 第一个月：机器学习直觉与 PyTorch 实验基础

## 月目标

从“知道名词”进入“能解释并实验”。月底应能独立完成一个小型分类实验，报告配置、曲线、均值、波动和错误样本。

每周完成 6 个可移动单元，每个 90-120 分钟。课程繁忙时按顺序延后，不跨过验收。

## 第 1 周：从线性回归理解训练

### 原理单元

1. 模型、参数、预测、标签、loss、训练分别是什么。
2. 标量/向量/矩阵、导数与链式法则的直观含义。

### 实践单元

3. 生成 `y = 3x + 2 + noise` 数据，用 NumPy 实现前向、MSE、梯度和更新。
4. 用 PyTorch autograd 重写同一实验。
5. 比较学习率 `0.001/0.01/0.1`，至少使用 3 个随机种子。

### 复盘单元

6. 画 loss 曲线并写 300 字结论：哪种设置稳定、为什么、还有什么不理解。

**验收题：**

- loss 为什么必须能够对参数求导？
- `zero_grad()` 为什么必要？
- 学习率过大和过小分别会出现什么现象？
- PyTorch 替你完成了什么，哪些仍由你决定？

## 第 2 周：分类与数据划分

### 原理单元

1. 训练集、验证集、测试集的分工；为什么不能用测试集调参。
2. logit、softmax、交叉熵、accuracy、precision、recall、F1。

### 实践单元

3. 使用 `Dataset/DataLoader` 读取 Fashion-MNIST。
4. 编写 MLP 的训练与验证循环。
5. 保存 checkpoint，重新加载并在测试集评估；画混淆矩阵。

### 复盘单元

6. 选择两个容易混淆的类别，人工查看至少 20 个错误样本。

**验收：** 能解释为何 accuracy 高仍可能不够；测试集在最终评估前只使用一次。

## 第 3 周：过拟合、优化与可复现性

### 原理单元

1. 过拟合、欠拟合、bias/variance 的直觉。
2. SGD、Adam、weight decay、dropout；理解作用，不要求完整推导。

### 实践单元

3. 故意使用小训练集制造过拟合。
4. 比较无正则化、weight decay、dropout 三个条件。
5. 固定配置文件、随机种子、日志目录和 checkpoint 命名。

### 复盘单元

6. 分析训练曲线，说明正则化对训练集和验证集分别产生什么影响。

**验收：** 换一台机器时，别人根据 README 能运行同一实验；知道完全数值一致与统计可复现的区别。

## 第 4 周：第一次研究式小实验

### 研究问题

在相近参数量和相同训练预算下，MLP 深度如何影响性能、收敛和稳定性？

### 必做内容

- 实验前写 hypothesis，不看结果后再改。
- 设计 2-3 个模型，尽量控制参数量。
- 每个条件运行 3 个随机种子。
- 报告均值、标准差、训练时间和参数量。
- 绘制训练/验证曲线。
- 对错误样本做定性分析。
- 写 1-2 页实验报告：问题、方法、设置、结果、结论、限制。

### 月末口头验收

不看资料解释：

1. 模型从数据中“学习”是什么意思？
2. 为什么训练准确率不是最终目标？
3. 为什么一次运行的结果不足以支持结论？
4. 如果验证结果变好、测试结果变差，可能发生了什么？
5. 这套实验流程将来如何迁移到 Agent？

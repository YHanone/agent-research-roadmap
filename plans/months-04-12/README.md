# 第 4-12 月：从 LLM 到独立研究

此计划以每月约 32-48 小时为基准。课程考试月可顺延，不允许用减少实验重复或跳过验收来赶进度。

## 第 4 月：完成 LLM 核心原理

### 第 13-14 周

- causal language modeling、交叉熵和 teacher forcing。
- 训练最小 GPT，检查 causal mask 和 overfit 单个 batch。

### 第 15 周

- greedy、temperature、top-k、top-p。
- 在固定 prompts 上比较正确率、多样性和稳定性。

### 第 16 周

- pretraining、instruction tuning、preference alignment 的作用边界。
- 阅读 InstructGPT；写 claim-evidence 笔记。

**产出：** 最小 Transformer、解码实验和架构说明。

**门槛：** 能解释训练目标为何不等于 Agent 成功；能定位 shape/mask 错误。

## 第 5 月：RAG 与 Tool Agent

### 第 17 周

- embedding、chunk、召回与重排。
- 在一组本地文档上构建普通 RAG，并标注检索错误与生成错误。

### 第 18 周

- JSON schema、function calling、参数验证。
- 实现计算器、文档检索和受限代码执行三个本地工具。

### 第 19 周

- 从零实现 Agent loop：state → model → action → tool → observation。
- 加入最大步骤、超时、重试和停止条件。

### 第 20 周

- 构造 50 个可自动验证任务。
- 比较 direct、RAG only、tool agent 的成功率、成本和失败类型。

**产出：** 无复杂框架的工具 Agent、轨迹日志和评测报告。

**门槛：** 能从失败轨迹区分模型、检索、工具、规划和解析错误。

## 第 6 月：Planning、Memory、Reflection

### 第 21 周

- 精读 ReAct，复现最小 thought/action/observation 循环。

### 第 22 周

- 实现 planner-executor 与 replan；明确计划何时作废。

### 第 23 周

- 实现最小 episodic memory：写入、检索、更新和容量限制。
- 与保留最近历史、摘要、向量检索比较。

### 第 24 周

- 实现 reflection；加入相同额外调用次数的重采样 baseline。
- 固定模型、任务与预算比较四种机制。

**产出：** 机制对比表、至少 30 条失败轨迹和失败分类。

**门槛：** 不使用“更智能”等模糊描述；每个结论对应指标和反例。

## 第 7 月：方向收敛与复现准备

### 第 25 周

- 精读 SWE-bench，理解任务构建、测试 patch 和污染风险。

### 第 26 周

- 精读 SWE-agent 与 Agentless，画出接口、检索、编辑和验证流程。

### 第 27 周

- 建立 10-15 篇论文矩阵。
- 比较任务、模型、预算、指标、代码可用性和资源成本。

### 第 28 周

- 选择复现对象和 10-20 个 pilot 任务。
- 固定论文版本、commit、环境、模型和预算。

**产出：** 复现 proposal：目标 claim、任务子集、资源预算、风险和停止条件。

**门槛：** 导师或同学能根据 proposal 判断实验是否公平、是否可完成。

## 第 8 月：Coding Agent Pilot

### 第 29-30 周

- 搭建隔离环境，完成 1-3 个 smoke test。
- 检查评测脚本能否正确识别成功和失败。

### 第 31 周

- 运行 10-20 个任务，记录 token、步骤、费用、时间和环境失败。

### 第 32 周

- 修正流程问题；冻结正式实验配置。
- 建立定位、规划、编辑、测试、工具、停止等失败类别。

**产出：** pilot 报告、成本估算和环境复现说明。

**门槛：** 环境失败与 Agent 失败可区分；预算足以完成下一月实验。

## 第 9 月：基线正式复现

### 第 33-35 周

- 运行选定规模的正式基线。
- 至少进行论文要求的重复，或清晰说明确定性/成本限制。
- 复现一个主要结果和一个关键消融。

### 第 36 周

- 生成结果表和失败案例。
- 比较原论文结果，分析数据、模型版本和环境偏差。

**产出：** 可公开复现报告和一条命令的最小运行流程。

**门槛：** 复现偏差有证据解释；不能通过手工挑样本得到主结论。

## 第 10 月：从失败到研究假设

### 第 37 周

- 对失败轨迹编码；抽查标注一致性。

### 第 38 周

- 选择高频、可测量、可能跨设置出现的失败现象。
- 形成至少 3 个原因假设，按证伪成本排序。

### 第 39 周

- 为每个假设设计最便宜的反证实验。
- 淘汰不受支持或只在个别样本出现的假设。

### 第 40 周

- 为保留假设设计最小方法和强简单 baseline。
- 预注册主要指标、子类分析和停止条件。

**产出：** 一页研究计划、因果图或变量表、pilot 结果。

**门槛：** 即使方法失败，实验仍能回答一个明确问题。

## 第 11 月：主实验、消融与泛化

### 第 41-42 周

- 原方法、强简单 baseline、完整方法、公平重采样 baseline。
- 固定预算，运行主要对比。

### 第 43 周

- 删除核心组件；改变阈值、预算或记忆容量。
- 报告哪些任务子类收益最大、哪些变差。

### 第 44 周

- 至少完成多模型或多任务子集中的一种泛化检查。
- 补充成本、延迟、稳定性和失败案例。

**产出：** 主表、消融表、成本表和代表性案例。

**门槛：** claim 不依赖单个模型、单次运行或少量人工挑选案例。

## 第 12 月：结果冻结与论文初稿

### 第 45 周

- 冻结评测协议；补齐缺失重复与人工抽查。
- 由脚本从原始结果生成所有表图。

### 第 46 周

- 写方法、实验设置、结果与限制。

### 第 47 周

- 写引言、相关工作和摘要。
- 检查每条 claim 对应哪张表或图。

### 第 48 周

- 技术审阅、表达审阅、复现审阅。
- 根据贡献选择投稿场所，制定补实验和投稿时间表。

**产出：** 论文初稿、匿名代码包、复现清单和投稿决策表。

**门槛：** 论文的核心结论在移除宣传性表达后仍清晰；他人能根据说明复现主要结果。

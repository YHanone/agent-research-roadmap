# 能力地图与知识取舍

## 初始判断

现有优势是算法思维、问题分解、C++ 调试能力和软件工程背景。主要缺口不是 Agent 框架，而是机器学习基本概念、数学直觉、PyTorch 实验能力和学术实验方法。

当前距离独立 Agent 研究大致有三层：

1. **基础层**：能够理解并修改神经网络实验。
2. **系统层**：能够解释 LLM Agent 的状态、决策、行动、观察和反馈循环。
3. **研究层**：能够提出可证伪假设，设计 baseline、控制变量、消融和失败分析。

## 阶段诊断规则

每一阶段按四个维度验收：

1. **解释**：不用术语堆砌，能说清机制为什么工作。
2. **实现**：不照抄教程，能独立完成最小版本。
3. **实验**：能控制变量、记录配置并解释异常。
4. **迁移**：能说明该知识在 Agent 系统中的位置。

任何阶段若只能通过“跟着教程复现”，都应增加一个变体实验后再进入下一阶段。

# 实践项目阶梯

项目按能力递进。不要同时开多个项目。

## P1：可复现分类实验

**阶段：** 第 1-2 月

**问题：** 模型深度或正则化如何影响泛化和稳定性？

**产出：** 训练代码、配置、3 个随机种子、图表、错误样本和 1-2 页报告。

## P2：最小 Transformer

**阶段：** 第 3-4 月

**问题：** 上下文长度和解码策略如何影响小型语言模型的输出？

**产出：** attention/Transformer 实现、shape 测试、训练曲线、生成分析。

## P3：无框架 Tool Agent

**阶段：** 第 5 月

**任务：** 使用本地文档检索、计算器和受限代码执行完成 50 个可验证任务。

**必要功能：** tool schema、参数验证、超时、重试、预算、日志和评测。

**对比：** direct answer、RAG only、ReAct/tool agent。

## P4：Agent 机制对比

**阶段：** 第 6 月

**问题：** Planning 或 Reflection 是否在公平预算下改善特定任务？

**对比：** direct、ReAct、planner-executor、reflection、相同调用次数重采样。

**产出：** 成功率、调用数、token、延迟和失败类型。

## P5：Coding Agent Pilot

**阶段：** 第 7 月

**任务：** 选择 10-20 个环境稳定、测试可运行的代码修复任务。

**目标：** 跑通 baseline、保存轨迹、估算成本、建立失败分类。此阶段不追求排行榜结果。

## P6：论文复现

**阶段：** 第 8-9 月

候选：SWE-agent 或 Agentless 的可承受子集，也可复现其中一个核心机制而非完整榜单。

**完成标准：** 一个主结果、一个关键消融、偏差说明和公开复现步骤。

## P7：研究项目

**阶段：** 第 10-12 月

只有完成 P6 后才能确定。优先候选问题：

- 固定预算下的错误恢复/重规划触发。
- Coding Agent 失败轨迹的可靠过程评估。
- 历史调试经验的选择性写入、检索和遗忘。
- 工具或测试异常下的鲁棒性评测。

选题必须包含可证伪假设，不能预先承诺正结果。
